# Booking service

## Quick start

```bash
docker compose up --build # сборка образа и запуск
docker exec -it booking-system python -m alembic upgrade head # запуск миграций
```
После этого приложение будет доступно на
http://127.0.0.1:8000/

Документация swagger:
http://localhost:8000/docs

## Ключевые решения и особенности
- При вставке новой брони может возникать race condition. Для того, чтобы этого не было был создан индекс
  ```sql
        CREATE UNIQUE INDEX uq_booking_active_slot 
        ON bookings(booking_date, booking_time) 
        WHERE status = 'active'
  ```
  Проверка отсутсвия гонок в [test_race_condition](tests/test_race_condition.py)
  В реальных системах бронирования скорее всего был бы промежуток времени для бронирования. В таком случае в postgress можно было бы сделать особый индекс. В sqlite пришлось бы лочить всю таблицу
